# webNovelTranslator

Автоматизирует перевод веб-новелл: вы сохраняете EPUB-файл, помещаете его в папку `to_translate`, запускаете скрипт — и вуаля!

Если скачали - вручную создайте папки:
1. all_result_books
2. result
3. temp
4. to_epub
5. to_translate

---

##  Что это?

- Позволяет перевести веб-новеллы, преобразовав их в формат EPUB с помощью расширения браузера вроде WebToEpub.
- После получения `.epub` файла, нужно:
  1. Очистить внутреннюю структуру папок (если требуется) - после запуска нажать на кнопку "Очистить".
  2. Поместить файл в каталог `to_translate`.
  3. Нажать на преобразование epub -> temp
  4. Перевести temp-файлы на язык с использованием онлайн-переводчика (Перевод xlsx файлов обычно хорошо проходит)
  5. Переведенные файлы поместить в папку `to_epub`
  6. Нажать на кнопку "Rus xlsx -> rus epub"
  7. В папке `results` появятся результаты.

---

##  Быстрый старт

1. Используйте расширение браузера (например, WebToEpub), чтобы скачать веб-новеллу в формате `.epub`.
2. Если в проекте уже есть содержимое в папках, его лучше очистить.
3. Скопируйте `.epub` файл в папку **`to_translate`**.
4. Запустите:
   ```bash
   python3 main.py
